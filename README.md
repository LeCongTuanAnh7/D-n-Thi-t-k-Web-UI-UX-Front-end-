# 📚 SmartLearn - Ứng dụng Ôn luyện Học tập

## 🌟 Giới thiệu (Introduction)
SmartLearn là một nền tảng/ứng dụng học tập được thiết kế để giúp học sinh ôn tập và củng cố kiến thức một cách hệ thống. Ứng dụng tập trung vào việc cung cấp môi trường luyện thi trực quan, bám sát các dạng câu hỏi thường gặp trong các kỳ thi quan trọng.

## 🚀 Tính năng nổi bật (Key Features)
* **Ngân hàng đề thi đa dạng:** Tích hợp bộ câu hỏi trắc nghiệm và bài tập thực hành cho các môn học cốt lõi như Vật lý, Lịch sử, và Địa lý.
* **Lời giải chi tiết (Step-by-step Solutions):** Cung cấp hướng dẫn giải quyết vấn đề từng bước một cho cả câu hỏi lý thuyết lẫn bài tập tính toán.
* **Trải nghiệm mượt mà (Seamless UX):** Kiến trúc luồng người dùng (user flow) được tối ưu hóa từ bước onboarding, chọn môn học, làm bài thi đến theo dõi kết quả.
* **Giao diện hiện đại (Modern UI):** Thiết kế trẻ trung, chú trọng vào typography với các điểm nhấn sử dụng hiệu ứng màu gradient bắt mắt để giảm cảm giác nhàm chán khi học tập.

## 🛠️ Công nghệ & Thiết kế (Tech Stack & Design)
* **Thiết kế UI/UX:** Cấu trúc Sitemap và User flow mô phỏng các ứng dụng giáo dục hiện đại.
* **Front-end:** HTML/CSS (tích hợp các kỹ thuật xử lý background clip cho text).
* **Back-end / Logic (Dự kiến):** Sử dụng Python để xử lý cấu trúc dữ liệu câu hỏi, tính điểm và phân loại logic bài tập.

## 📂 Cấu trúc Repository (Folder Structure)
* `/docs`: Chứa sitemap, biểu đồ luồng người dùng (flowcharts) và tài liệu đặc tả dự án.
* `/ui-mockups`: Các bản thiết kế giao diện tĩnh.
* `/src`: Mã nguồn chính của ứng dụng.

## ⚙️ Hướng dẫn sử dụng (How to use)
1. Clone repository về máy local: `git clone https://github.com/LeCongTuanAnh7/your-repo-name.git`
2. Mở file `index.html` trong thư mục `/src` để xem trước giao diện.
3. Đọc kỹ các tài liệu trong thư mục `/docs` để hiểu rõ luồng hoạt động của app.
